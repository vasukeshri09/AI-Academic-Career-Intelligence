# AI-Powered Academic and Career Intelligence Platform

An AI-powered platform that provides personalized academic and career guidance to students.

## Core Features

- Student skill profiling
- Career recommendation
- Skill gap analysis
- Career readiness assessment
- Personalized learning roadmap
- AI-powered career assistant
- RAG-based academic and career guidance

## Tech Stack

- Python
- FastAPI
- React / Next.js
- PostgreSQL
- pgvector
- Scikit-learn
- Sentence Transformers
- Large Language Models
- Retrieval-Augmented Generation (RAG)
- Docker
